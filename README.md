# Hill-Number-Area-Curves
Code for https://arxiv.org/abs/2609.02365

crw_simulation_python.py samples from the stationary distribution and outputs a list of lists indicating which sites in the [0, N)^2 box belong to the same species. The output should look like [[x_1, x_2, ...], [y_1, y_2, ...], ....], and each inner list corresponds to sites with the same species (eg x_1, x_2, etc belong to the same species and y_1, y_2, etc belong to another). Each value in the list is an integer that is converted to a site by the map x->(x%N, x//N) where % is mod and // is integer division.

CRW_simulate.cpp was generated by asking AI to translate crw_simulation_python from python to C++. This runs significantly faster. We emphasize no functionality was added.

generate_Fig2A.py and generate Fig2BC.py use the output of CRW_simulate.cpp to generate the plots in figure 2 of the paper. Please note that this code assumes (1) the data outputs are in the same folder on the same level as them and (2) the data outputs have the same name convention that CRW_simulate.cpp spat out. For some computers, the line plt.show() may need to be commented out. The two scripts should output png files of the figures.

exact_plotted_points.txt give the (x, y) coordinates of the points in Fig2ABC. Due to stochasticity, values using the above scripts may generate different values, but they should be pretty close.
